# 5.2.3 — Simple Module SDK example

See `plugins/examples/SimpleModule/README.md` for the standalone build and study guide. Host changes are generic: Options accepted by menu registry, register_tab routes to the editor, register_panel with Bottom routes to Output, Tab routes to editor, Left/Right route to workspace sidebar. Existing native adapters remain unchanged. Generic views are identified by registered ID, reused while open and closable in editor/output. Terminal-only operations on generic output views no longer accidentally target the local shell. Settings remain generated by the existing plugin settings registry.

Test: `ctest --test-dir build -R '^(simple_module_sdk|native_plugin_integration)$' --output-on-failure` after building both targets. GUI requires wxWidgets; headless tests exercise registration, routing decisions, settings and view content with a mock UI builder.
