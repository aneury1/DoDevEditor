# wxWidgets 5.0.1
- Start shell on workspace open, and on first command if stopped. Input is the separate line field below output. Enter submits, Ctrl+C without selected input interrupts. Terminal > Start shell restarts the shell. Errors and exit codes are shown in output. Copy and Export available.
- View > Dark theme / Light theme, persisted in wxConfig. Default dark. Palette API: src/gui/wx/WxTheme.h (Theme::dark/light, apply, editor, docking). Native menus/buttons/tab chrome can follow OS appearance; not all platforms honor control colours.
- Files tab is now one native tree with folder/file icons, lazy enumeration, double-click file open, context menu operations, hidden files visible. Directory symlinks are not recursively expanded. Refresh resets expansion. Root remains independent of navigation.
- Existing line-input terminal is not a full interactive terminal emulator. GUI build and runtime require wxWidgets development libraries and a desktop session.
