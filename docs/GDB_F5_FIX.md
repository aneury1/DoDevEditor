# GDB F5 diagnostics (4.1.1)
F5 and the Run menu now exist even when the plugin has not been approved or loaded. Plugin approval is still required. Enable com.dodev.gdb in Settings > Plugins and restart. A missing plugin or an exception in the debugger produces a dialog; action dispatch is logged to stderr. Plugin actions are bound before shortcuts are installed. User keyboard overrides remain respected. Use --foreground to inspect logs. If clicking Run works but F5 does not, verify Settings > Keyboard Shortcuts > gdb.start and reset it to F5. Native GUI and actual keyboard delivery require testing on the target machine.
