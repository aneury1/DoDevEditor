# DoDevEditor 5.1.8 — Modular CMake and build portability

- Root CMake reduced from 299 to 26 lines; focused modules document options, dependencies, targets, installation and tests.
- No Raven source fetch in the active build. Existing application features and plugin identifiers are retained.
- wxWidgets include directories, definitions, compile flags and libraries are now target-local. Missing mandatory dependencies fail with actionable diagnostics. GTK3 CSS remains optional.
- GDB shares the existing services target, eliminating duplicate JSON and terminal task compilation. PIC is enabled for static libraries used by plugins.
- AI HTTP can be disabled without removing the plugin. Tests check actual transport availability rather than variables local to another CMake directory.
- Plugin filenames match manifests on Windows and macOS; separate CLI output names avoid case-insensitive executable collisions. Multi-config runtime paths are colocated with plugin manifests; separate build trees per configuration are recommended.
- Existing Linux wxWidgets install RPATH helper retained. All 7 bundled plugin files/manifests verified by staging a headless install.
- Four Ninja presets and updated build scripts. Compilation database enabled for supported generators. Assertions remain enabled in optimized test executables.

## Actual verification

Environment: Linux x86_64, GCC 14.2.0, CMake 3.31.6, Ninja.

- Headless Debug with full optional plugins and AI HTTP enabled: compiled; 43/43 CTest tests passed after refactoring.
- Headless Release minimal preset (AI HTTP, QR, examples disabled): compiled; 36/36 CTest tests passed.
- Linux runtime-path fixture: passed as part of both suites.
- Staged headless installation: 7 plugin binaries and their manifests installed.
- GUI configuration without wxWidgets: fails with intended actionable dependency message. No native GUI compilation or Windows/macOS runtime validation performed.
- `dodeveditor --version`: reports 5.1.8.

The exact failure on the second PC is unknown. See [BUILD_SYSTEM.md](BUILD_SYSTEM.md) for diagnostic commands and known platform limitations.
